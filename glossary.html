Словарь терминов

В таблице собраны основные термины книги с краткими определениями. Последний столбец указывает раздел, в котором термин введён и разобран подробно.

Основные термины
Термин English Определение Где введён
актор actor Узел социальной сети, понимаемый как сущность, способная действовать: человек, организация, государство. Сети вокруг нас и теория графов
ассортативность assortativity Мера того, насколько чаще связи соединяют узлы с одинаковым значением признака, чем при случайном смешивании. Гомофилия
брокер, посредник broker Узел, через который проходят пути между частями сети, плохо связанными напрямую. Центральность по степени
вес связи tie weight Число, выражающее силу связи: число писем, встреч, минут разговора. Направленные и взвешенные сети
взаимность reciprocity Доля связей направленной сети, на которые есть ответная связь. Взаимность
взвешенная сеть weighted network Сеть, связи которой имеют веса. Направленные и взвешенные сети
входящая степень in-degree Число связей, которые узел получил в направленной сети. Степень узла
вырожденность модели model degeneracy Свойство модели порождать нереалистичные сети, например почти пустые или полные. Оценка и проверка модели
гармоническая центральность harmonic centrality Среднее значение величин, обратных расстояниям от узла до остальных узлов. Недостижимые узлы дают нулевой вклад. Центральность по близости
геометрически взвешенная статистика geometrically weighted statistic Статистика ERGM, в которой вклад каждой следующей конфигурации убывает в геометрической прогрессии. Оценка и проверка модели
гетерофилия heterophily Тенденция связей чаще соединять узлы с разными значениями признака. Гомофилия
гомофилия homophily Тенденция связей чаще соединять похожие узлы, чем это происходило бы случайно. Гомофилия
граф graph Математический объект из множества узлов и множества связей между ними. Сети вокруг нас и теория графов
двудольная сеть bipartite network Сеть с узлами двух типов, в которой связи соединяют только узлы разных типов. Двудольные сети
диада dyad Любая пара узлов независимо от наличия связи между ними. Взаимность
диаметр diameter Наибольшее расстояние между узлами сети. Пути и расстояния
исходящая степень out-degree Число связей, которые узел отправил в направленной сети. Степень узла
кластеризация, коэффициент кластеризации clustering coefficient Доля пар соседей узла, которые сами связаны между собой. Кластеризация
коллокация collocation Пара слов, которые встречаются в тексте рядом. От коллокаций к графу
корпус corpus Набор текстов, которые анализируются вместе. Корпус и разметка
лемма lemma Начальная форма слова. Корпус и разметка
маршрут walk Последовательность связей, в которой узлы могут повторяться. Центральность по собственному вектору
матрица смежности adjacency matrix Квадратная таблица, в которой на пересечении строки \(i\) и столбца \(j\) записано наличие или вес связи между узлами \(i\) и \(j\). Способы записи сетей
матрица смешивания mixing matrix Таблица числа связей между категориями узлов: строки соответствуют отправителям, столбцы получателям. Гомофилия
модулярность modularity Превышение доли связей внутри групп над долей, ожидаемой при случайном размещении связей. Сообщества и модулярность
направленная сеть, орграф directed network, digraph Сеть, связи которой идут от одного узла к другому. Направленные и взвешенные сети
нормализация normalization Приведение показателя к шкале от 0 до 1 делением на наибольшее возможное значение. Центральность по степени
окрестность neighborhood Множество соседей узла. Степень узла
перепись диад dyad census Подсчёт пустых, асимметричных и взаимных диад направленной сети. Взаимность
плотность density Доля реализованных связей среди всех возможных. Плотность
полный граф complete graph Граф, в котором связаны все пары узлов. Плотность
проекция двудольной сети projection Сеть из узлов одного типа, в которой два узла связаны при наличии общего соседа другого типа. Двудольные сети
путь path Последовательность связей, ведущая от одного узла к другому. Пути и расстояния
размер сети network size Число узлов сети. Обозначения
распределение степеней degree distribution Доли узлов, имеющих каждое возможное значение степени. Средняя степень и распределение степеней
расстояние distance Длина кратчайшего пути между двумя узлами. Пути и расстояния
реализация модели realization Отдельная сеть, полученная из вероятностной модели. Модели G(N, L) и G(N, p)
связь tie, edge, link Отношение между двумя узлами. Сети вокруг нас и теория графов
семантическая сеть semantic network Сеть слов, в которой связь означает соседство слов в тексте. 7  Практикум: семантическая сеть
смежность adjacency Отношение двух узлов, между которыми есть связь. Степень узла
согласие модели с данными goodness of fit (GOF) Сравнение наблюдаемой сети с сетями, симулированными из модели, по характеристикам, не входившим в модель. Оценка и проверка модели
сообщество community Группа узлов с большим числом связей внутри и малым числом связей с остальной сетью. Сообщества и модулярность
список связей edgelist Таблица, в которой каждая строка описывает одну связь парой узлов. Способы записи сетей
средняя степень mean degree Среднее число связей на узел. Средняя степень и распределение степеней
статистика изменения change statistic Изменение статистик сети при появлении одной связи. Модель
статистика сети network statistic Числовая характеристика сети, входящая в ERGM: число связей, взаимных диад, треугольников. Модель
степень узла degree Число связей узла. Степень узла
случайный граф random graph Сеть, связи которой возникают случайно, независимо друг от друга и с одинаковой вероятностью. Модели G(N, L) и G(N, p)
токен token Отдельная единица текста: слово или знак препинания. Корпус и разметка
транзитивность transitivity Доля замкнутых троек среди всех троек вида «A связан с B, B связан с C». Кластеризация
узел node, vertex Элемент сети: человек, организация, слово. Сети вокруг нас и теория графов
центральность по близости closeness centrality Величина, обратная среднему расстоянию от узла до остальных узлов. Центральность по близости
центральность по посредничеству betweenness centrality Сумма долей кратчайших путей между парами других узлов, проходящих через данный узел. Центральность по посредничеству
центральность по собственному вектору eigenvector centrality Центральность, пропорциональная сумме центральностей соседей узла. Центральность по собственному вектору
центральность по степени degree centrality Центральность, равная числу связей узла. Центральность по степени
эго ego Узел, с точки зрения которого рассматривается его окружение. Кластеризация
экспоненци­альная модель случайного графа exponential random graph model (ERGM) Вероятностная модель сети, в которой вероятность сети зависит от её статистик. Модель
PageRank PageRank Вариант центральности по собственному вектору для направленных сетей: доля времени, которую случайный путник проводит на узле. Центральность по собственному вектору
PMI, точечная взаимная информация pointwise mutual information Логарифм отношения доли пары слов к доле, ожидаемой при независимом расположении слов. От коллокаций к графу
